# Review Writer 轻量工具说明

项目不再规定固定阶段，也不再生成“通过、就绪、放行、完成”状态。

模型直接阅读论文并写一份 Markdown 正文。需要什么工具就调用什么工具：

```text
检索与合法全文入库
MinerU PDF 解析
元数据与本地全文搜索
论文图片盘点
图片、图表和反应式插入
稳定引用编号与参考文献生成
Markdown -> DOCX -> PDF
真实页面渲染与人工/模型视觉检查
```

以下文件不再是必需品：

```text
literature_matrix.json
section_blueprint.json
section_drafts.json
semantic_audit_queue.json
figure_fidelity_review.json
review_state.json
quality_gate_*.json
finalizer 或 experiment status
```

模型可以按需要写提纲、阅读笔记、对比表或风险清单，但它们只是工作材料。
脚本只能完成确定性的查找、复制、计数、编号、格式化和渲染，不能替模型声明
证据充分、图片可合法复用、语义审校通过或页面视觉合格。

字数没有全局硬阈值。`review-writing-tools` 会根据正文中实际引用且可定位到
本地全文的文献数量给出建议区间；这个区间只用于发现“资料很少却写得异常长”
或“资料很多却几乎没有综合”的情况，不阻止继续写作或导出。

论文原图和反应式先通过 `review-source-figure-tools` 盘点，再由模型查看完整
原页、图注和许可信息，最后用 `review-citation-assets` 的显式插入标记放入
正文。候选图、空白裁剪、页面碎片和脚本生成的 provenance 都不能冒充模型
已经完成的图像判断。
