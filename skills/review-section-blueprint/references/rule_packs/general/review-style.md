# General review style

## Voice

Write for a reader choosing how to understand or use the literature. Lead with the review's judgment, then provide enough evidence to evaluate it. Prefer concrete verbs and specific scientific nouns.

## Information order

Use the order that fits the paragraph's job:

```text
claim -> evidence -> comparison -> boundary -> consequence
problem -> approaches -> decision-relevant differences -> remaining gap
observation -> competing explanations -> evidence strength -> implication
```

## Comparisons

Name the comparison axis before presenting results. Useful axes include material or population, intervention or method, conditions, outcome definition, performance, uncertainty, operational burden, and failure modes.

## Uncertainty

Put the qualification beside the claim:

```text
The source observed X under Y conditions.
The authors attributed X to Z.
The result is consistent with Z but does not distinguish it from W.
Within the retained corpus, X appears in ...
```

Use a bounded positive statement instead of a paragraph organized around possible objections.

## Openings and transitions

Open sections with the question or distinction that organizes them. Transitions state what changed: a new substrate class, stronger evidence, a different mechanism, an operational tradeoff, or an unresolved boundary.

## Conclusions

Conclude with the capabilities established, the method differences that matter, the strongest remaining boundaries, and the next questions that follow from the evidence.
